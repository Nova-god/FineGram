# FineGram

Unofficial Telegram client with custom design.

FineGram is an unofficial Android client based on the Telegram open-source project.

## Original project

This project uses the source code of the official Telegram for Android:
https://github.com/DrKLO/Telegram

## Development

FineGram is an independent project. Its interface and functionality may be customized.

## Telegram API

API documentation: https://core.telegram.org/api
